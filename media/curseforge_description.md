**Replacement for the default XP bar**

1. Tracks XP/hour
2. Provides estimated time to level up
3. Will track completed quests in your quest log
4. Shows rested XP on the bar
5. Hover the bar for time played this level and this session

![Example](https://media.forgecdn.net/attachments/description/1711903/description_8de25923-2b18-4a83-8349-5f2ed22884ed.png)

**Options**

Ctrl+Right-click the bar, type `/kxp options`, or go to Escape -> Options -> AddOns -> Krrl XP Bar.

1. Edit font, including fonts shared by other addons through LibSharedMedia (EllesmereUI, SharedMedia packs, etc.)
2. Edit font size
3. Edit bar skin
4. Resize the bar with sliders, by typing a size, or by dragging the corner grip
5. Lock the bar so it can't be moved or resized
6. Reset to defaults

**Commands**

- `/kxp options` - open the options window
- `/kxp lock` - lock/unlock the bar
- `/kxp` - list all commands
