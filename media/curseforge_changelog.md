## 1.0.1

**New**

- Options window: Ctrl+Right-click the bar, type `/kxp options`, or go to Escape -> Options -> AddOns -> Krrl XP Bar
- Font: pick any game font, plus fonts shared by other addons through LibSharedMedia (EllesmereUI, SharedMedia packs, etc.). Type in the dropdown to filter
- Font size: slider, or type a number (6-32)
- Bar texture: built-in textures plus any shared through LibSharedMedia
- Bar size: set width and height with sliders, by typing a number, or by dragging the grip in the bar's corner while options are open
- Lock bar: checkbox or `/kxp lock` stops the bar from being moved or resized
- Reset to Defaults for appearance settings
- Bar tooltip shows how to open options and whether the bar is locked
